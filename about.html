Overview

这是一个怎样的网站

纯静态个人站，离线可用，无需构建环境，可直接部署到 GitHub Pages。

功能特性

首页包含个人介绍、数据统计、关于我 / 技能、精选项目、最新博客与联系方式六大板块；另有项目展示页与个人博客页。支持暗色模式与侧边栏收起 / 展开。

技术说明

纯 HTML + CSS + 原生 JavaScript，零依赖、零构建。所有页面互链与静态资源均使用相对路径，任意静态托管可直接运行。

设计来源

视觉语言（奶油米背景、深蓝主色、圆角卡片与衬线大标题）借鉴 Continuation Writing Studio V4.8 —— 一个离线使用的英语读后续写数字教材项目；本站将强调色由金色调整为青绿。

维护信息

站点内容（统计数字、项目、文章、联系方式）目前为占位，可通过编辑各页面 HTML 直接替换；样式与交互参数集中在 css/style.css 与 js/main.js。
